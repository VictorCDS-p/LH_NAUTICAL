Q7 - SISTEMA DE RECOMENDAÇÃO

Produto de referência: Motor de Popa 1949

Q7.1 - Construção da matriz e similaridade

Foi construída uma matriz de interação Usuário × Produto com 2.000 clientes e 500 produtos.

Cada linha representa um cliente (id_cliente) e cada coluna representa um produto (id_produto). O valor da célula é 1 quando o cliente comprou aquele produto pelo menos uma vez e 0 quando não houve compra. A quantidade comprada foi desconsiderada, conforme solicitado.

Foram identificadas 135.508 interações únicas entre clientes e produtos.

A partir dessa matriz, foi calculada a Similaridade de Cosseno entre os vetores de cada produto. Dessa forma, a similaridade entre dois produtos representa o quanto os mesmos clientes tendem a comprar ambos.

Q7.2 - Ranking dos produtos similares

Considerando o "Motor de Popa 1949" como produto de referência, os 5 produtos mais similares foram:

1. Motor de Popa 5331 — Similaridade: 0.2566
2. Cabo Náutico 2105 — Similaridade: 0.2562
3. Vela Mestra 1913 — Similaridade: 0.2558
4. Cabo Náutico 9048 — Similaridade: 0.2393
5. GPS Plotter 6249 — Similaridade: 0.2377

O produto com maior similaridade ao "Motor de Popa 1949" é o "Motor de Popa 5331", com similaridade de 0.2566.

Q7.3 - Explicação

1. Como a matriz foi construída?

A matriz foi construída a partir das compras realizadas pelos clientes. Cada cliente ocupa uma linha e cada produto ocupa uma coluna. Quando um cliente comprou determinado produto pelo menos uma vez, a célula recebe valor 1. Caso contrário, recebe 0. Compras repetidas do mesmo produto pelo mesmo cliente continuam representadas apenas pelo valor 1.

2. O que significa a similaridade de cosseno nesse contexto?

A similaridade de cosseno mede a proximidade entre os padrões de compra de dois produtos. Um valor maior indica que os produtos são comprados por conjuntos de clientes mais semelhantes. Assim, para o "Motor de Popa 1949", o "Motor de Popa 5331" foi o produto que apresentou o padrão de clientes mais semelhante entre os produtos avaliados.

3. Qual é uma limitação desse método?

Uma limitação é a dependência do histórico de compras. Produtos novos ou com poucas compras podem não possuir informações suficientes para gerar recomendações confiáveis. Além disso, o método considera apenas a presença ou ausência da compra, não levando em conta quantidade comprada, valor da compra, recência ou contexto da compra.
