Q7.1 - MATRIZ USUÁRIO × PRODUTO
------------------------------------------------------------

Foi construída uma matriz de interação Usuário × Produto
contendo:

- 2.000 clientes;
- 500 produtos;
- 135.508 interações únicas entre clientes e produtos.

Cada linha representa um cliente (id_cliente) e cada coluna
representa um produto (id_produto).

O valor da célula é:

- 1: o cliente comprou o produto pelo menos uma vez;
- 0: o cliente não comprou o produto.

A quantidade comprada foi desconsiderada, conforme solicitado
no enunciado.

Para evitar que compras repetidas gerassem valores superiores
a 1, as interações foram previamente deduplicadas e a matriz
foi transformada em uma representação binária.


Q7.1 - SIMILARIDADE DE COSSENO
------------------------------------------------------------

A similaridade foi calculada entre os vetores dos produtos.

Cada produto é representado pelo conjunto de clientes que
realizaram pelo menos uma compra daquele produto.

A Similaridade de Cosseno mede a proximidade entre esses
vetores de clientes. Dessa forma, quanto maior o valor da
similaridade, mais semelhantes são os padrões de clientes
que compraram os dois produtos.

Q7.3 - EXPLICAÇÃO
------------------------------------------------------------

Como a matriz foi construída?

A matriz foi construída a partir das compras realizadas pelos
clientes. Cada cliente representa uma linha e cada produto
representa uma coluna.

Quando um cliente comprou determinado produto pelo menos uma
vez, a respectiva célula recebe o valor 1. Caso contrário,
recebe o valor 0.

Assim, compras repetidas do mesmo produto pelo mesmo cliente
não aumentam o valor da célula, mantendo a representação de
presença ou ausência solicitada no desafio.


Como a Similaridade de Cosseno funciona nesse contexto?

A Similaridade de Cosseno compara os vetores de clientes
associados a dois produtos.

Nesse contexto, produtos apresentam maior similaridade quando
são comprados por conjuntos de clientes mais semelhantes.

Para o "Motor de Popa 1949", o "Motor de Popa 5331" apresentou
o maior valor de similaridade entre os produtos analisados,
com score de 0,2566.


Qual é uma limitação desse método?

Uma limitação é a dependência do histórico de compras. Produtos
novos ou com poucas interações podem não possuir informações
suficientes para gerar recomendações confiáveis.

Além disso, como a matriz é binária, o método considera apenas
a presença ou ausência da compra. Portanto, não considera
quantidade comprada, valor da compra, recência ou contexto da
transação.
