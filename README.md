# Lighthouse Challenge — Dados e IA

Projeto desenvolvido para o desafio técnico da Lighthouse, com foco em análise e exploração de dados da LH Nautical.

O projeto contempla desde a estruturação e carregamento dos dados em PostgreSQL até análises utilizando SQL e Python, incluindo análise exploratória, análise de clientes, previsão de demanda e sistema de recomendação.

Também foi desenvolvido um dashboard em Power BI para apresentar visualmente os principais indicadores e insights identificados durante as análises.

## Tecnologias utilizadas

- **Python** — automação, análise de dados, previsão e recomendação
- **Pandas** — manipulação e análise dos dados
- **NumPy** — cálculos numéricos e similaridade
- **PostgreSQL** — armazenamento e consulta dos dados
- **SQL** — exploração, validação e análises
- **Power BI** — visualização dos dados e desenvolvimento do dashboard
- **psycopg2** — conexão entre Python e PostgreSQL
- **python-dotenv** — gerenciamento das variáveis de ambiente

## Principais etapas

- Análise exploratória dos dados (EDA);
- Inferência e criação do schema PostgreSQL;
- Carregamento dos arquivos CSV no banco de dados;
- Análises de clientes e categorias;
- Análise de vendas por dia da semana;
- Previsão de demanda utilizando média móvel;
- Sistema de recomendação baseado em similaridade de cosseno;
- Desenvolvimento de dashboard no Power BI.

## Dashboard

O projeto inclui um dashboard desenvolvido no **Power BI**, com o objetivo de apresentar os principais indicadores e insights de forma visual e facilitar a interpretação dos dados.
